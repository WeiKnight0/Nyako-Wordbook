# 05 界面与键盘交互

> 当前桌面首屏先显示非白色启动状态，存储后台就绪后进入词库；受阻时显示错误。当前词条界面不提供标签或媒体操作，导入/导出在数据管理页使用十列 XLSX 或 JSON v2，旧库迁入不提供软件入口。下文含标签、媒体、学习界面的段落是旧设计或后续设想。

## 1. 信息架构与布局

主导航：今日、复习、词库、未分类、设置；标签作为词库列表的筛选区域，而不是尚未实现的层级标签树。

宽窗口采用左导航、中列表、右详情三栏。建议最小窗口尺寸 960×640 CSS 像素；详情区可折叠。低于约 1200 宽时默认双栏，详情改为侧抽屉；200% 系统缩放下仍需通过折叠和内容滚动访问所有操作，不强制显示三栏。

| 页面 | 主要内容 | 首要操作 |
| --- | --- | --- |
| 今日 | 今日新词、评分次数、复习词数、到期数、最近词库 | 开始复习、导入 |
| 词库列表 | 名称、词条数、到期数、归档状态 | 新建、选择词库 |
| 词条列表 | 写法、读音、首义项、词性、标签、学习状态/到期 | 搜索、筛选、新增、批量操作 |
| 词条详情 | 完整义项、音调、例句、备注、所属词库、媒体 | 编辑、播放、暂停/恢复 |
| 复习 | 范围选择、卡片、进度、预计间隔、快捷键提示 | 显示答案、评分 |
| 设置 | 学习、外观、数据、诊断 | 保存、备份、恢复 |

列表只显示首义项并以“另有 N 项”提示；详情展示全部，不用单元格撑高所有行。表头允许排序，排序状态可见。列宽、详情显隐、主题等视图偏好可保存，但不混入词库交换文件。

## 2. 词条编辑

当前词库页以搜索、写法／读音、中文首义项为主；默认显示 JLPT 和词性筛选，排序、卡片状态与到期选项收进“更多筛选与排序”。列表与详情显示中文词性，不暴露英文编码。编辑对话框将必填的写法、假名、义项置前；词性区分动词活用类别和可留空的自动词／他动词属性，例句、音调、所属词库与备注默认折叠，已有内容自动展开且收起时不清空草稿。新增时聚焦写法；纯假名词在写法和假名均填假名。标签和媒体仍属后续设想。

- 列表型字段使用“新增义项/新增例句”操作，可重排；提交时保留稳定 ID。
- 空必填字段就地提示，保存后端失败显示表单级错误并保留输入。
- 编辑撞到 revision 冲突时展示当前版本差异，允许复制本地内容后重载，不以自动覆盖替代选择。
- 标签选择同时支持搜索已有标签和明确创建新标签，不在输入法组合输入结束前创建。
- 新增重复候选仅作提醒，可明确选择继续新建。

## 3. 焦点与快捷键分层

优先级：系统/输入法 → 原生菜单和对话框 → 活动弹窗 → 文本编辑控件 → 当前页面 → 应用。所有应用快捷键仅在应用窗口内生效，MVP 不注册系统全局热键。

`Primary` 在 macOS 为 Cmd，Windows/Linux 为 Ctrl。输入控件内保留复制、粘贴、撤销、方向键和数字输入；composition 期间停止处理页面级 Enter、Space、字母和数字热键。按键长按产生的 repeat 不得重复评分或连续打开对话框。

| 作用域 | 按键 | 行为 |
| --- | --- | --- |
| 应用 | Primary+F | 聚焦当前词汇搜索，必要时切至词库页；不覆盖编辑弹窗 |
| 应用 | Primary+N | 打开新词表单；已有脏表单时先处理其状态 |
| 列表 | ↑/↓ 或 J/K | 改变单一活动行，确保滚动可见 |
| 列表 | Enter | 打开当前行详情，不执行删除或保存 |
| 列表 | Space | 切换当前行勾选，不与复习翻牌混用 |
| 列表 | Shift+↑/↓ | 扩展选区；选区总数保持可见 |
| 编辑表单 | Primary+Enter | 校验并保存 |
| 弹窗/抽屉 | Escape | 关闭；有未保存内容时先显示选择 |
| 复习 Question | Space/Enter | 显示答案 |
| 复习 Answer | 1/2/3/4 | Again/Hard/Good/Easy；提交中禁用 |
| 复习 | Primary+Z | 撤销最后一次评分；文本框内保留文本撤销 |
| 复习 | R | 播放发音（M3），无音频时禁用并解释 |
| 窗口 | F11（平台可替代） | 切换沉浸模式（M3）；菜单始终有对应入口 |

Answer 状态的 Space/Enter 不默认提交 Good，避免用户连续翻牌误打分。所有快捷操作同时提供有名称的按钮；帮助面板按当前作用域展示有效快捷键。

弹窗开启时保存原焦点，Tab/Shift+Tab 在弹窗内循环；关闭后恢复到原触发元素，元素不存在则回到页面主标题。列表刷新后按 ID 恢复活动行，删除后选择相邻行。

## 4. 搜索、筛选和批量操作

搜索框 200 ms 防抖，输入法提交后才发查询。请求带序号或取消令牌；新请求开始后旧响应不再更新列表。加载时保留旧结果并标识更新中，空结果和加载失败必须区别。

筛选以可移除条件标签展示。每次搜索/筛选变化清空跨查询选择并提示，避免误把旧选择用于新范围。批量工具条显示选中数量、标签、加入/移出词库、暂停/恢复及删除。删除词条位于危险操作区，不与“移出词库”使用相同图标和文案。

## 5. 导入与恢复界面

导入向导对应 03 的阶段，每一步明确可返回和是否会写入。映射预览并列展示原值与解释结果；错误行可筛选查看。冲突差异标明“保留”“填空”“替换”，集合覆盖显示完整前后集合。

提交期间可继续只读浏览，但编辑、评分、恢复等写操作显示任务占用原因。取消请求显示“正在安全取消”，只有后端确认回滚后才显示取消完成。后台任务完成后提供结果入口，不因用户切换页面丢失报告。

恢复使用独立界面，不放进普通导入向导；显示备份日期、词条数、事件数、媒体数、数据库版本与“将覆盖当前全部数据”。用户确认前完成验证，确认后才进入维护和切换。

## 6. 桌面增强（M3）

### 沉浸模式

进入后隐藏应用导航和非必要工具栏，系统全屏能力由平台窗口 API 决定；不能保证隐藏所有系统浮层。提供明显的退出按钮与 Escape/F11，离开时恢复原窗口位置和最大化状态。

### 迷你窗口

独立小窗可建议以 360×240 起始尺寸，支持折叠和可选置顶。展示当前卡、翻牌、四级评分、播放和退出小窗；折叠态不能隐藏退出入口。与主窗口共享同一会话状态，任一窗口评分成功后另一窗口同步，不能同时创建独立正式队列。

边缘吸附为可选增强；Linux Wayland 等环境可能不允许定位或置顶，失败时提示并保留可拖动普通窗口。保存窗口位置前记录显示器信息，重启或移除显示器后把窗口恢复到可见区域。小窗默认不抢占其他应用键盘焦点，也不通过全局数字键评分。

## 7. 音频与富文本（M3）

音频默认不自动播放；用户启用后在题面显示时播放一次。切卡、关闭窗口或开始新音频时停止旧音频；同一卡多窗口只允许当前活动展示窗口播放。文件缺失、解码失败时保留学习操作，显示附件错误和重新关联入口。

Markdown 渲染禁用原始 HTML、远程图片、脚本和内联事件；本地资源仅使用后端授权的媒体 ID。外部链接显示目标域名，明确点击后调用系统浏览器；渲染本身不能发网络请求。

## 8. 界面验收

必须以真实键盘、日文输入法、200% 缩放、深浅主题和三平台执行关键路径。检查无鼠标完成新增、搜索、编辑、开始复习、打分和退出；检查输入中文释义中的数字/空格/J/K 不会触发页面热键。复习提交失败时当前答案仍然可见，多窗口和长按键不会重复评分。
