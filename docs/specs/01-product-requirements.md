# 01 产品需求与范围

> 当前实现范围：词汇内容仅采用十列单表可表达的字段；正式数据库位于 `data/main.sqlite3`，旧版数据删除，不提供软件内迁入；仅支持 XLSX 与 JSON v2 交换。下文标签、媒体、CSV、旧库迁移及学习功能相关描述是早期路线或后续设想，不是当前功能与兼容承诺。

## 1. 目标、用户与边界

目标用户为使用个人桌面设备、已具备基础日语知识、需要自行管理日中词汇的学习者。首版采用单机单用户模型：每个操作系统用户具有独立数据目录；多个词库共享词条和学习进度。

产品应支持以下核心场景：

| 场景 | 用户目标 | 完成条件 |
| --- | --- | --- |
| 导入学习材料 | 将自己的表格转成词库 | 能预览、映射字段、处理冲突，提交后给出逐类结果 |
| 整理词汇 | 查找、纠错、分类 | 修改立即持久化，重启后可见，原有学习记录保留 |
| 每日复习 | 优先复习到期内容，再学新词 | 每次评分持久化，退出后不丢进度 |
| 数据迁移 | 更换设备或恢复误操作 | 备份恢复后内容、学习状态、媒体一致 |
| 碎片练习 | 使用小窗或测验巩固 | 不打断主窗口状态，不重复计入调度 |

明确不纳入当前路线：账户登录、多用户协作、云同步、联网词典抓取、自动翻译、OCR、在线 TTS、自动生成并判定任意日语变形。未来增加网络功能必须重新定义隐私与授权。

## 2. 版本优先级

- **M1**：词库/词条/义项/例句/标签管理；普通文本备注；日文检索；CSV/JSON 导入导出；本地备份恢复。
- **M2**：单一认词卡、FSRS 调度、每日队列、打分与撤销、暂停/埋藏、基础学习统计、完整键盘路径。
- **M3**：XLSX、分块二进制包、媒体与音频播放、受限 Markdown 备注、沉浸模式、迷你窗口。
- **M4**：独立四选一练习、人工配置答案的例句填空、增强学习统计。

后续阶段不能反过来阻塞 MVP；MVP 界面隐藏尚未交付的操作入口。

## 3. 功能需求

### FR-LIB 词库管理（M1）

- 创建词库时名称去除首尾空白后必填，建议长度 1—100 个 Unicode 字符；名称允许相同，界面用描述、创建时间辅助区分。
- 支持重命名、描述编辑、归档、删除和词条批量加入/移出。
- 归档后不进入默认复习范围，内容仍可搜索和导出。重新启用后按当前到期时间排队，不自动平移历史时间。
- 移出词库只删除成员关系。删除词库需要确认；保留词条及学习记录，未归属任何词库的词条可在“未分类”中找到。
- 永久删除词条是单独操作，须显示会删除的成员关系、卡片与历史记录，并二次确认；先建议备份。该操作不提供会话撤销。

### FR-WORD 词条管理（M1，富文本与媒体 M3）

新增词条的最低有效信息为：非空假名、至少一个非空中文义项；汉字写法可空，纯假名词可正常使用。编辑采用显式保存，取消不写库；离开脏表单时提供保存、放弃、继续编辑。

词条可包含多个词性、多个释义、多个例句和多条音调记录；例句允许没有中文翻译。音调数值与具体读音关联，必须记录按拍数计算的下降位置；未知与平板型 0 必须区分。不能把多个读音挤入一个 `kana` 字段；首版不同读音建立不同词条。

普通备注保存为文本；M3 可采用受限 Markdown，禁用原始 HTML、脚本和自动外链资源。音频为本地附件，复制到受管理媒体目录，不能仅保存用户原文件的绝对路径。

编辑词条、例句、标签不得改变卡片的到期时间。重置学习状态必须是明确的单独操作，确认后保留重置前事件以供追溯。

### FR-TAG 标签（M1）

标签使用扁平多对多模型，首版不实现层级树。标签名去空白、Unicode NFC 归一化后唯一；大小写敏感，避免对日文和外文名称做隐式合并。支持批量添加、移除、重命名；删除标签仅删除关联，不删除词条。JLPT 等级保存为独立可空字段 N5—N1，不依赖标签命名。

### FR-SEARCH 检索与浏览（M1）

- 支持汉字、假名、中文释义及备注检索；默认忽略拉丁字母大小写，片假名/平假名等价查询，保留原始显示。
- 查询输入按空白拆为关键词，各词采用 AND；字段内连续子串匹配。中文分词、罗马音转假名、拼写纠错不作为首版承诺。
- 筛选包括词库、标签（全部/任一）、JLPT、词性、卡片状态、到期与否。熟练度查询使用明确状态或可解释的调度指标，不沿用无定义的 `srs_level<3`。
- 支持写法、读音、更新时间、下次复习时间排序；相同排序值追加 ID 保证顺序稳定；空到期时间在最后。
- 查询采用分页与虚拟列表；新查询取消旧请求，旧响应不得覆盖新结果。
- 批量操作明确作用于“当前已选 N 条”；全量匹配操作使用独立确认并显示总数，不能仅凭页面上的勾选框推断。

### FR-IO 文件交换（M1/M3）

拖入支持的文件或从菜单选择文件后进入同一个导入向导。顺序为文件检查、字段映射、样本预览、全量校验、冲突选择、确认、提交、结果。规则见 [03](03-import-export.md)。导出用户选择的词库或词条时显示数量与是否包含媒体；词库交换不默认携带个人学习历史。

### FR-STUDY 学习（M2/M4）

M2 提供“看日文 → 回忆中文 → 显示答案 → 四级评分”流程。未显示答案时禁止评分，评分成功后才切换下一张。具体调度和撤销见 [04](04-learning-srs.md)。

基础统计显示今日引入的新词数、有效评分次数、不同复习词数、当前到期数；统计必须区分次数和词数。学习时长仅累加卡片前台活跃时间，单次响应上限见调度规格；不以打开窗口的总时长代替。

M4 测验与填空默认作为独立练习，不修改 FSRS 卡片；自动选择题的正确答案不能直接代表用户回忆评分。

### FR-DATA 设置与数据安全（M1/M2）

设置包括数据位置展示、每日新词限额、日切时间、主题、字体大小、音频自动播放（M3）。MVP 数据目录由操作系统标准应用目录确定，不提供运行时移动数据库操作。

启动时执行版本检查和必要迁移；迁移前创建可验证备份。用户可主动创建备份、查看备份信息、恢复和打开目录。恢复前展示覆盖范围并自动备份当前数据。错误时保留原数据并提供诊断信息，不自动创建空库掩盖故障。

## 4. 通用交互规则

- 长任务展示当前阶段、已处理数量、可取消状态；不足一秒的操作不强制显示进度条。
- 保存失败保留用户输入；导入失败显示行号/字段/原因，不只显示错误代码。
- 空词库提供新增/导入入口；无搜索结果保留筛选并允许一键清除；无到期词时允许结束或进入不影响调度的额外练习。
- 删除、重置、恢复与冲突覆盖显示具体影响，不使用泛化的“确定吗”。
- 应用关闭时处理未保存表单和运行中写任务；完成提交或安全取消后才退出。

## 5. 功能验收样例

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| AC-01 | 将同一词条加入两个词库，在其中一处编辑 | 两处显示同一更新；复习状态仅一份 |
| AC-02 | 导入两个无 ID、同写法同读音但义项不同的条目 | 提示候选冲突，允许分开保存，不静默覆盖 |
| AC-03 | 编辑已复习词条的释义后重启 | 新释义存在，原到期时间保持 |
| AC-04 | 删除某个词库 | 其他词库和全部词条仍可用，卡片与历史保留 |
| AC-05 | 保存失败后继续编辑 | 表单内容仍在，重试成功后仅产生一次修改 |
| AC-06 | 日文输入法组合输入时按 Enter/数字 | 只处理输入法确认，不触发新增、翻牌或评分 |
| AC-07 | 恢复包含媒体的完整备份 | 词条、队列、统计与可播放媒体均恢复 |

## 6. 隐私与可访问性

核心流程在断网环境可用；不上传词汇、文件名、学习历史或崩溃上下文。日志默认只记录模块、错误类别、内部任务 ID 和耗时，避免记录释义、备注和文件全文。用户主动导出诊断信息前可预览内容。

常规界面与系统缩放兼容，至少支持 100%—200%；颜色不作为状态的唯一表达。所有关键操作具有可见按钮与键盘入口，焦点可见，屏幕阅读器可获取按钮名、表格列名和评分说明。
